# 🤖 AI Bot Builder

The builder should allow users to create bots without writing code.

Example:

```
IF

RSI < 25

AND

EMA 10 crosses EMA 50

AND

AI Confidence > 90%

THEN

BUY

ELSE

WAIT
```

Every condition should be draggable.
