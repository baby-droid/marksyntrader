Execution Modes
Execution Modes

1. Normal Mode
- Human-like execution
- Wait for contract confirmation
- Uses inter-contract delay
- Safe and stable

2. Crazy Mode
- Remove all intentional delays
- No inter-contract cooldown
- Prepare next order while current order is processing
- Purchase immediately when signal is confirmed
- Skip unnecessary animations and UI updates
- High execution priority

3. Turbo Mode
- Everything in Crazy Mode
- Zero intentional software delays
- Pre-build purchase payloads before signal
- Persistent WebSocket connection
- Instant API request on trigger
- Parallel processing for analysis and execution
- Non-blocking order queue
- Dedicated execution thread
- Highest execution priority
- Immediate re-entry after contract settlement
Pseudocode
IF mode == NORMAL
    wait(interContractDelay)
    analyze()
    buyContract()

IF mode == CRAZY
    interContractDelay = 0
    analyze()
    buyImmediately()

IF mode == TURBO
    interContractDelay = 0
    preloadContract()
    keepWebSocketAlive()

    IF signal == TRUE
        sendPurchaseRequestImmediately()
