---

This architecture gives you a complete, extensible Blockly/XML system that can power a visual trading workflow builder. Developers can add new block types through the plugin API, serialize workspaces to XML, compile them into an execution graph, and run them through a modular runtime while keeping the broker integration, scanner, risk controls, logging, and UI cleanly separated. It is flexible enough to support many workflow types without hard-coding specific automated betting strategies.
