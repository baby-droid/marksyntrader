From the screenshots, Deriv is using **three separate UI systems** that work together:

1. **Contract Lifecycle Engine** (handles tick counting and contract result)
2. **Chart Annotation Engine** (places the flags and markers)
3. **Digit Probability Display** (highlights the winning/losing digit)

If you're building an identical platform, the logic is approximately as follows.

---

# 1. User Executes Contract

Example

```
Contract : OVER
Barrier  : 2
Duration : 1 Tick
Stake    : $10
```

Save the trade.

```ts
const contract = {
    id: uuid(),
    type: "OVER",
    barrier: 2,
    duration: 1,
    ticksRemaining: 1,
    startTickIndex: tickIndex,
    startPrice: currentQuote,
    status: "RUNNING"
}
```

Immediately draw

```
Blue vertical line
Countdown (0/1)
Blue circle
```

# 14. State Machine

```
BUY

↓

Pending

↓

Tick Counter

↓

Settlement

↓

Extract Last Digit

↓

Evaluate

↓

WIN / LOSS

↓

Update Graph

↓

Highlight Digit

↓

Save History

↓

Ready for Next Trade
```

This architecture can be reused across **all Deriv digit contracts** (Over/Under, Odd/Even, Matches/Differs) by keeping the visualization layer generic and only changing the evaluation rule for each contract type. The chart annotations (blue countdown, settlement marker, win/loss flag), digit highlighting, and history logging remain the same regardless of contract type; only the predicate that determines whether the settlement digit wins changes.
