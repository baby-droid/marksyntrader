For a professional trading platform, don't design for fixed pixel sizes. Use a **responsive layout system** with breakpoints, flexible widths, and scalable components. This is how platforms like Deriv, TradingView, and Binance keep their interfaces usable across phones, tablets, laptops, ultrawide monitors, and 4K displays.

---

# 1. Responsive Breakpoints

| Device           | Width       | Layout                    |
| ---------------- | ----------- | ------------------------- |
| Small Mobile     | 320–479px   | Single column             |
| Mobile           | 480–767px   | Single column             |
| Tablet Portrait  | 768–991px   | Chart + collapsible panel |
| Tablet Landscape | 992–1199px  | 70/30 layout              |
| Laptop           | 1200–1439px | 74/26 layout              |
| Desktop          | 1440–1919px | 76/24 layout              |
| Large Desktop    | 1920–2559px | 78/22 layout              |
| 4K               | 2560px+     | Max-width centered layout |

# 3. Responsive Widths

Instead of

```css
width:360px;
```

use

```css
width:min(360px,25vw);
min-width:280px;
max-width:380px;
```

Chart

```css
flex:1;
```

---

# 4. Responsive Font Sizes

Instead of

```css
font-size:16px;
```

use

```css
font-size:clamp(14px,1vw,16px);
```

Examples

| Element     | Size                   |
| ----------- | ---------------------- |
| Header      | clamp(18px,1.4vw,28px) |
| Price       | clamp(18px,1.6vw,30px) |
| Buttons     | clamp(16px,1vw,20px)   |
| Digit       | clamp(18px,1.3vw,24px) |
| Probability | clamp(10px,.8vw,13px)  |

# 23. Media Query Settings

```css
/* Large Desktop */
@media (min-width:1920px){
    --panel-width:360px;
    --digit-size:64px;
    --button-height:60px;
}

/* Desktop */
@media (1440px <= width < 1920px){
    --panel-width:350px;
    --digit-size:60px;
    --button-height:58px;
}

/* Laptop */
@media (1200px <= width < 1440px){
    --panel-width:330px;
    --digit-size:56px;
    --button-height:56px;
}

/* Tablet */
@media (768px <= width < 1200px){
    --panel-width:300px;
    --digit-size:52px;
    --button-height:54px;
}

/* Mobile */
@media (max-width:767px){
    --panel-width:100%;
    --digit-size:48px;
    --button-height:52px;
}
```

# 24. Recommended UI Specification

| Component    | Desktop | Laptop | Tablet | Mobile |
| ------------ | ------- | ------ | ------ | ------ |
| Chart        | 76%     | 74%    | 100%   | 100%   |
| Right Panel  | 24%     | 26%    | 100%   | 100%   |
| Digit Circle | 64px    | 56px   | 52px   | 48px   |
| Digit Gap    | 18px    | 16px   | 12px   | 8px    |
| Trade Button | 60px    | 58px   | 54px   | 52px   |
| Header       | 72px    | 68px   | 60px   | 56px   |
| Price Font   | 30px    | 26px   | 22px   | 20px   |
| Body Font    | 16px    | 15px   | 14px   | 13px   |
| Chart Height | 78vh    | 72vh   | 60vh   | 45vh   |

This approach ensures the trading interface remains readable and fully functional from a 320 px-wide mobile screen to a 4K desktop without requiring browser zoom, while keeping the chart, trading controls, digit indicators, and action buttons consistently accessible.
