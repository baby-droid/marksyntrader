# Exact Prompt for an AI Builder

```text
Build a pixel-perfect trading dashboard inspired by the Deriv Trader interface shown in the reference image.

Requirements:
- React + TypeScript + Tailwind CSS + Vite.
- Use TradingView Lightweight Charts for the live area chart.
- Full-width header with market selector card on the left.
- Horizontal digit-frequency bar at the top displaying digits 0–9 inside circular indicators with percentages beneath each digit.
- Main content split into two columns:
  - Left: responsive live area chart with gridlines, right-side price axis, and a faint diagonal "DERIV TRADER" watermark.
  - Right: trading panel (360px wide) with sections for Contract Type, Duration slider, Last Digit Prediction (0–9 grid), Stake/Payout selector, stake controls, and two large buttons: Over (teal) and Under (red).
- Bottom of the chart contains another digit-frequency row matching the top style.
- Theme:
  - Background: #F8F9FA
  - Cards: white with 10px radius and subtle shadow
  - Primary: #00B8A9
  - Danger: #F44336
  - Borders: #E5E7EB
  - Font: Inter
- Responsive layout:
  - Desktop: 70% chart / 30% trading panel
  - Tablet: 60% / 40%
  - Mobile: stacked layout.
- Include smooth 200ms transitions for live updates.
- Use reusable React components and maintain clean, modular code.
```

These settings will produce a UI that is **very close in look and layout** to the screenshot while remaining an original implementation rather than a literal copy of Deriv's proprietary interface.
