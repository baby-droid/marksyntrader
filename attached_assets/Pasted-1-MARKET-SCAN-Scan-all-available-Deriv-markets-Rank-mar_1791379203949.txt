1. MARKET SCAN
→ Scan all available Deriv markets.
→ Rank markets by signal quality.
→ Select only markets with sufficient tick history and valid contract availability.

2. TICK ANALYSIS
Use:
→ 1000 ticks = primary market regime
→ 100 ticks = structure
→ 50 ticks = momentum
→ 20 ticks = confirmation
→ 10 ticks = entry timing

3. DIGIT ANALYSIS
For digits 0–9 calculate:
→ frequency %
→ recent frequency %
→ streak
→ gap
→ recurrence
→ momentum
→ distribution change
→ pattern repetition
→ concentration
→ entropy

4. PATTERN ANALYSIS
Detect:
→ AAA
→ AAAA
→ ABAB
→ AABB
→ ABBA
→ ABA
→ ABC
→ repeated digits
→ alternating digits
→ alternating EVEN/ODD
→ digit clusters
→ digit gaps

Pattern alone must NEVER trigger an entry.

5. EVEN SIGNAL
Calculate EVEN % across:
1000 / 100 / 50 / 20 / 10

Generate EVEN only when:
→ long-term distribution supports EVEN
→ short-term momentum supports EVEN
→ 20-tick confirmation supports EVEN
→ 10-tick entry trigger supports EVEN
→ no major contradiction exists.

6. ODD SIGNAL
Same logic as EVEN, inverted.

7. MATCH SIGNAL
Find the strongest candidate digit.

Require:
→ strong distribution
→ increasing recurrence
→ short-term confirmation
→ 20-tick confirmation
→ 10-tick entry trigger.

Output:
MATCH + ENTRY DIGIT.

8. DIFFERS SIGNAL
Find weak/low-concentration digits.

Require:
→ low concentration
→ high distribution dispersion
→ weak recurrence
→ no strong dominant digit
→ multi-window confirmation.

Output:
DIFFERS + EXCLUDED DIGIT.

→ momentum confirms

11. RISE SIGNAL
Calculate:

UP = current tick > previous tick
DOWN = current tick < previous tick

Generate RISE when:
→ 1000 regime supports upward movement
→ 100/50 structure is bullish
→ 20 confirms momentum
→ 10 produces entry trigger
→ reversal/chop is low.

12. FALL SIGNAL
Inverse of RISE.

13. ONLY UP
Require:
→ persistent upward movement
→ low reversal frequency
→ positive 50/20 momentum
→ positive 10-tick trigger
→ low chop.

14. ONLY DOWN
Require the inverse.

15. HIGH TICK
Analyze:
→ rolling highs
→ new-high frequency
→ distance from high
→ breakout/rejection behavior
→ 20/10 confirmation.

16. LOW TICK
Analyze:
→ rolling lows
→ new-low frequency
→ distance from low
→ breakdown/rejection behavior
→ 20/10 confirmation.

17. SIGNAL SCORE

SignalScore =
MarketQuality
+ DistributionStrength
+ PatternStrength
+ Momentum
+ MultiWindowAgreement
+ EntryTiming
+ Stability
- Noise
- Contradiction

Normalize to 0–100.

20. ENTRY DIGIT

For MATCH:
→ return strongest confirmed digit.

For DIFFERS:
→ return weakest confirmed digit as excluded barrier.

For OVER:
→ return selected barrier 1–7.

For UNDER:
→ return selected barrier 8–1.

For EVEN/ODD:
→ no digit barrier unless the selected contract requires one.

23. SIGNAL INVALIDATION

Immediately cancel the signal when:

→ multi-window agreement disappears
→ entry condition disappears
→ market becomes noisy
→ strategy reverses
→ selected barrier loses statistical support
→ signal expires
→ risk limit is reached.

→ do NOT blindly repeat.

After maximum consecutive losses:
→ STOP
→ clear signal
→ wait for a new setup.
