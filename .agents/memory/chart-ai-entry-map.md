The chart AI treats the supplied reference map as an entry gate only for Over/Under contracts: Strong Over = 3, 4, 1, 8; Strong Under = 9, 6, 2; Under 5 is excluded. Weak digits may inform analysis but must not trigger an Over/Under order.

**Why:** The user’s reference distinguishes strong entry digits from weak/avoid digits, so selecting a valid barrier alone is not enough to justify an entry.

**How to apply:** Preserve the gate alongside the existing 50-tick distribution and historical-duration checks. Do not apply this map to unrelated contract groups such as Rise/Fall or Even/Odd.
